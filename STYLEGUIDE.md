# Travel Planner Style Guide 

## Colour Palette

### Ocean Blue
- Hex: #2563EB
- Used for primary buttons and links

### Sky Blue
- Hex: #DBEAFE
- Used for backgrounds and highlighted sections

### Dark Navy
- Hex: #1E293B
- Used for headings and primary text

### White
- Hex: #FFFFFF
- Used for main backgrounds

### Slate Gray
- Hex: #64748B
- Used for secondary text

## Typography

The application uses Arial, Helvetica, sans-serif.

### Main Heading

- Size: 32px
- Weight: 700

### Section Heading

- Size: 24px
- Weight: 600

### Body Text

- Size: 16px
- Weight: 400
